# FAQ Index

An FAQ as a card-index drawer. Each question is typed along a card’s edge with its subject on a staggered tab; pull one and it lifts out to show the answer. An accordion underneath.

**[See it running, with every option](https://tactileui.dev/blocks/faq-drawer)**

Open `index.html` over HTTP (`npx serve .`) to run it here. `faq-drawer.mjs` is the class and `faq-drawer.css` its look; no framework, no build step, no dependencies.

Or install it into a project with shadcn:

```sh
npx shadcn add https://tactileui.dev/r/faq-drawer.json
```
