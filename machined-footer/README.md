# Machined Footer

A footer made as the bottom panel of a device. Printed columns of links, a status window with a real lamp, a changelog key, an Aluminium / Graphite switch for the whole page, the build number stamped in.

**[See it running, with every option](https://tactileui.dev/blocks/machined-footer)**

Open `index.html` over HTTP (`npx serve .`) to run it here. `machined-footer.mjs` is the class and `machined-footer.css` its look; no framework, no build step, no dependencies.

Or install it into a project with shadcn:

```sh
npx shadcn add https://tactileui.dev/r/machined-footer.json
```
