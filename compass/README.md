# Compass

A liquid-damped compass. The card swings past the mark and settles while a lit display reads the bearing. Your hand turns the knurled bezel, one click a degree.

**[See it running, with every option](https://tactileui.dev/objects/compass)**

Open `index.html` over HTTP (`npx serve .`) to run it here. `compass.mjs` is the class and `compass.css` its look; no framework, no build step, no dependencies.

Or install it into a project with shadcn:

```sh
npx shadcn add https://tactileui.dev/r/compass.json
```
