# Engraved Client Plates

“Used in production by…”, as metal name plates. Brushed aluminium or anodised black, screwed or riveted, each client’s mark cut into the metal with one quiet number under it.

**[See it running, with every option](https://tactileui.dev/blocks/client-plates)**

Open `index.html` over HTTP (`npx serve .`) to run it here. `client-plates.mjs` is the class and `client-plates.css` its look; no framework, no build step, no dependencies.

Or install it into a project with shadcn:

```sh
npx shadcn add https://tactileui.dev/r/client-plates.json
```
