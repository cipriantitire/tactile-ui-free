# Pull-cord Bulb

A pendant lamp that is a switch. Pull the acorn: the detent resists and snaps, and the filament warms from dull red to white while the lamp sways. It can switch the whole page’s finish.

**[See it running, with every option](https://tactileui.dev/objects/pull-cord)**

Open `index.html` over HTTP (`npx serve .`) to run it here. `pull-cord.mjs` is the class and `pull-cord.css` its look; no framework, no build step, no dependencies.

Or install it into a project with shadcn:

```sh
npx shadcn add https://tactileui.dev/r/pull-cord.json
```
